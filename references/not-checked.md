# 確認しないもの

ここにあるものは、どれも資料に載っています。それぞれ、理由があって外してあり、戻す条件も書いてあります。これらが無いことを、問題として報告しません。

## 脱獄の検知、デバッガの検知、難読化、改ざんの検知

OWASP は、これらを耐性のための対策としてまとめ、無いこと自体は脆弱性ではない、と明記しています。対象は、事業上の資産を守るアプリや、不正やチートを抑える必要があるアプリです。

Apple の App Attest の文書にも、関係する指摘があります。ただし、脱獄やデバッガの検知には触れていません。指摘の内容は、アプリは自分自身の確認を自分の処理に任せられない、ということです。乗っ取られたアプリは、結果を偽れるためです。App Attest が結果をサーバーに送るのは、そのためです（B20）。

静的な検査ツールは、「脱獄の検知が無い」を、満たしていない推奨事項としてよく報告します。それは、このアプリにそこまでの手間をかけて守るものがあるかを考えるきっかけとして扱います。問題としては扱いません。

**戻す条件**: アプリが、コンテンツを売っている。人どうしを順位で競わせている。または、お金の入ったアカウントを持っている。

出どころ: [MASVS-RESILIENCE](https://mas.owasp.org/MASVS/11-MASVS-RESILIENCE/) · [Establishing your app's integrity](https://developer.apple.com/documentation/devicecheck/establishing-your-app-s-integrity)

## 証明書の固定

OWASP は、開発者が管理している接続先について、証明書の固定を求めています。Apple は、これを、既定の信頼の評価を任意で厳しくするものとして説明しています。固定には、続けていく手間もかかります。証明書が変わったのにアプリが更新されていないと、アプリは動かなくなります。

**戻す条件**: アプリが、個人情報を扱う自前のサーバーと通信していて、固定した証明書を入れ替えていく計画がある。

出どころ: [MASVS-NETWORK-2](https://mas.owasp.org/MASVS/controls/MASVS-NETWORK-2/) · [Performing manual server trust authentication](https://developer.apple.com/documentation/foundation/performing-manual-server-trust-authentication)

## ペーストボードをまったく使わないこと

検査ツールの中には、共通のペーストボードを使っている箇所をすべて報告するものがあります。コピーは、人が当然あると思っている機能です。このスキルが見るのは、アプリ自身が書き込む個人情報だけです（B11）。

## メモリの破壊、書式文字列、ヌル文字の差し込み

これらは、C と Objective-C の問題です。Swift のコードが、これらにさらされることは、ほとんどありません。Swift で気をつける場合は、`String(format:)` のように、外から来た値で書式文字列を組み立てているときです。

Xcode の任意の設定である Enhanced Security も、ここに入ります。コンパイラと実行時の保護を強めるもので、その多くは C と C++ のコードに関わります。スキャンは、設定されているかどうかだけを報告します（A7）。

**戻す条件**: スキャンが、C 系のソースファイルを報告した。または、アプリが、外から来たデータを渡す C のライブラリをリンクしている。この範囲は、古いチェックリストが扱っています。[secure-ios-app-dev](https://github.com/felixgr/secure-ios-app-dev) を見ます。

## パッケージの既知の脆弱性を調べること

OWASP は、アプリが、既知の脆弱性の無い部品だけを使うことを求めています。それに答えるには、固定した版を脆弱性のデータベースと照らす必要があり、リポジトリを読むだけではできません。このスキルは、その照合ができる状態になっているかまでを確認します。版が固定されていて、ロックファイルがコミットされているかです（C3）。調べていないことを、報告に書きます。

**戻す条件**: ロックファイルを読むツールを、実行できる。

出どころ: [MASVS-CODE-3](https://mas.owasp.org/MASVS/controls/MASVS-CODE-3/)

## データがバックアップに入るかどうか

Apple は、ファイルをバックアップから外す指定を、システムへの目安であって保証ではない、と説明しています。直し方を当てにできない確認は、報告する価値がありません。秘密の値は、代わりにキーチェーンに置きます（B7、B9）。

出どころ: MASTG-TEST-0215（STORAGE）。この点についての Apple の文書を引用しています

## プライバシーの表示と、App Review への適合

プライバシーマニフェスト、用途の説明文、プライバシーポリシー、App Store のプライバシーの詳細は、アプリがデータの使い方を正直に示しているかと、審査を通るかを決めるものです。これは、別の資料にもとづく別の点検で、このスキルは行いません。
